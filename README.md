# 🔗 URL Shortener

A full-stack URL Shortener application built with **Spring Boot**, **React**, and **PostgreSQL**. It enables users to generate short URLs from long links and seamlessly redirects them to the original destination.

## 🚀 Features

- Generate unique short URLs
- Redirect to original URLs
- RESTful API
- PostgreSQL database integration
- Responsive React frontend
- Input validation and error handling

## 🛠️ Tech Stack

**Frontend:** React, HTML, CSS, JavaScript

**Backend:** Java, Spring Boot, Spring Data JPA

**Database:** PostgreSQL

**Tools:** Maven, Git, Postman

## ⚙️ Getting Started

### Clone the repository

```bash
git clone https://github.com/Lingesh-13/Url-Shortner.git
```

### Backend

```bash
cd backend
mvn spring-boot:run
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
